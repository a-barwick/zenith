# Language Specifications

These documents record Zenith's intended observable behavior. They guide
implementation but do not replace executable evidence.

- [Language foundations](language-foundations.md)
- [Lexical structure](lexical-structure.md)
- [Diagnostics](diagnostics.md)
- [Governor effects](governor-effects.md)

Every rule is labeled **Implemented**, **Planned**, **Proposed**, or
**Deferred** when its state is not obvious. Proposed syntax may change before
its roadmap milestone begins.

`docs/COMPATIBILITY.md` is the summary of shipped capability. A specification
must never be interpreted as an implementation claim.
